# Setup Guide — ScopeForge

This guide covers **prerequisites, quickstart, daily development, verification, and troubleshooting** for the structured monorepo at `AgentHarness/`.

ScopeForge is two local processes:

- **TypeScript CLI/TUI** (`apps/terminal`) — owns the terminal, never contacts targets.
- **Python engine** (`services/engine`) — owns policy, egress, evidence, and is the **only** process that may open target sockets.

They speak **JSON-RPC 2.0 over NDJSON stdio** (`packages/protocol-schema` → generated `protocol-ts` + `protocol_generated.py`). No remote transport in MVP.

---

## 1. Prerequisites

| Tool | Version | Install | Verify |
|---|---|---|---|
| **Node** | LTS ≥ 20 | `nvm install --lts` / [nodejs.org](https://nodejs.org) | `node --version` |
| **pnpm** | ≥ 9 | `npm i -g pnpm` / `brew install pnpm` | `pnpm --version` |
| **Python** | **3.12+** | `uv python install 3.12` (see note) | `uv run python --version` |
| **uv** | ≥ 0.5 | `curl -LsSf https://astral.sh/uv/install.sh \| sh` | `uv --version` |
| **Git** | any | Xcode CLI Tools / `brew install git` | `git --version` |

> **Python 3.11 note (2026-09-16):** The spine (`services/engine/src/scopeforge_engine/server.py`) is stdlib-only and runs on 3.11. Full stack (pydantic/anyio/httpx, 106 engine tests) requires 3.12. If your system is 3.11, run `uv python install 3.12 && uv sync --python 3.12 --all-extras` — the repo-local `.venv` will use 3.12 without touching system Python.

Optional for browser phase:

```bash
uv sync --extra browser   # Playwright capture (opt-in, Phase 7)
```

No Docker, no cloud account, no telemetry required. All runs are local files + rebuildable SQLite.

## 2. One-command quickstart

From repo root (`AgentHarness/`):

```bash
# 1. JS deps (frozen lockfile — reproducible)
pnpm install --frozen-lockfile

# 2. Python env (frozen lockfile — reproducible)
uv sync --python 3.12 --all-extras --all-packages

# 3. Generate protocol bindings (checked in; CI fails on drift)
pnpm generate:protocol

# 4. Verify (all green before you touch anything)
pnpm lint
pnpm test
uv run pytest services/engine/tests -q
python -m pytest services/engine/tests -q   # bare-interpreter portability gate (stdlib-only paths)
node scripts/generate-protocol.mjs --check
```

Expected (Sep 2026, darwin x64, Node 24, Python 3.12):

```
> tsc --noEmit -p tsconfig.json      # lint: 0 errors
Test Files  12 passed  Tests  48 passed
106 passed (uv) / 93 passed (bare python, http-gated tests skipped)
drift ok
```

## 3. Repository layout (plan.md §12)

```

├── apps/terminal/           # TypeScript CLI + plain TUI (never contacts targets)
│   └── src/{commands, tui, views, launcher, providers-toml, ...}.ts
├── services/engine/         # Python engine (policy, egress, evidence — only target I/O)
│   └── src/scopeforge_engine/{server, policy, egress, evidence, runs, agent, models/*, ...}.py
├── packages/
│   ├── protocol-schema/     # JSON Schema source of truth (protocol.json, 44 methods)
│   ├── protocol-ts/         # Generated TS types + EngineClient + redact
│   └── provider-fixtures/   # Sanitized replay exchanges (generated by scripts/make-provider-fixtures.py)
├── schemas/                 # Domain schemas (engagement, case, coverage, evidence)
├── labs/tenancy-demo/       # Local intentionally-vulnerable app (loopback only)
├── curriculum/              # T01–T12 coverage catalog (24 checks)
├── evals/golden/            # Artifact-only T02.1 golden run (no live traffic)
├── tests/{contract,e2e,unit} # TS tests
├── services/engine/tests/   # Python tests (stdlib + anyio/httpx)
├── docs/{adr,*.md}          # Product + engineering docs (this folder)
├── scripts/{generate-protocol.mjs, launcher.mjs, sbom.py, make-provider-fixtures.py}
├── .github/workflows/ci.yml # Matrix CI (Linux/macOS/Windows) + SBOM/provenance
├── pnpm-workspace.yaml / package.json / vitest.config.ts
├── pyproject.toml + services/engine/pyproject.toml + uv.lock
└── sbom.json / provenance.json  # Generated, not hand-edited
```

**Dependency rules** (`docs/development.md`, enforced in review):

- `domain` imports no provider/UI/DB/HTTP/tool.
- `policy` depends only on domain + pure helpers.
- Executors receive an approved capability from policy.
- Providers never call tools.
- UI never duplicates policy logic.
- Generated protocol code is checked in; drift fails CI.

## 4. Daily development loop

```bash
# Make a change
pnpm generate:protocol          # if you touched packages/protocol-schema/protocol.json
pnpm lint
pnpm test                       # 12 files, 48 tests — includes 10k-event soak + crash-resume
uv run pytest services/engine/tests -q   # 106 tests — includes live-lab egress (httpx) where available
```

Focus a single area:

```bash
pnpm vitest run tests/unit/cli.test.ts
uv run pytest services/engine/tests/test_policy.py -k test_canonicalization -q
pnpm dlx -y tsx apps/terminal/src/index.ts --help
```

### Protocol changes

`packages/protocol-schema/protocol.json` is the source of truth. Never hand-edit generated files:

```bash
node scripts/generate-protocol.mjs          # writes packages/protocol-ts/src/generated.ts
                                            # and services/engine/src/scopeforge_engine/protocol_generated.py
node scripts/generate-protocol.mjs --check  # CI drift gate
```

### Provider fixtures

Sanitized exchanges are generated, never hand-escaped:

```bash
uv run python scripts/make-provider-fixtures.py
# scans for secret shapes via scan_fixture_file (fail closed)
```

## 5. CLI surface (plan.md §4.2)

Every scriptable command supports `--json` and `--no-color`. Exit codes are stable:

`0 ok` · `1 fail` · `2 usage/config` · `3 not implemented` · `4 policy blocked` · `5 approval declined` · `6 provider` · `7 tool` · `8 budget exhausted` · `9 partial/inconclusive`

```
scopeforge init [--home DIR]
scopeforge doctor
scopeforge tui [--run ID] [--plain] [--once]

scopeforge provider add --name N --type T [--base-url U] [--credential env:VAR]
scopeforge provider test PROVIDER [--model M] [--no-live]
scopeforge models list [--provider P] | inspect PROVIDER:MODEL

scopeforge run start --mode plan|artifacts|live | --lab tenancy-demo
scopeforge run list | status | resume | cancel | close --run ID
scopeforge case new --check T02.1 ... --run ID
scopeforge case list | show | retry --run ID
scopeforge artifact import FILE... --run ID
scopeforge har import FILE --run ID | burp import FILE --run ID
scopeforge evidence show EID --run ID [--preview] | redact EID --run ID
scopeforge report build --run ID --finding-file F.json
scopeforge export RUN_ID [--include-originals]
scopeforge program import POLICY_FILE [--run ID]
scopeforge scope show --run ID | validate HOST_OR_URL [--run ID]
scopeforge mcp add NAME COMMAND | list | enable NAME | disable NAME
scopeforge tool list | invoke --name N --executable PATH [--args A] [--target-url U]
```

- `--yes` never bypasses live-target, credential, destructive, or policy gates.
- `live` mode is Phase-5-gated: `run start --mode live` is refused until scope review lands (use `plan|artifacts` or `--lab tenancy-demo`).
- Mode badge (`plan`/`artifacts`/`live`) is always visible; secrets are referenced (`env:VAR`), never stored.

## 6. Local lab (no internet, no credentials)

The default lab is `tenancy-demo` (two tenants, two accounts, one project, loopback only):

```bash
# Via CLI (spawns loopback server, scopes a live run, budgets enforced):
pnpm dlx -y tsx apps/terminal/src/index.ts init --home /tmp/demo-home
pnpm dlx -y tsx apps/terminal/src/index.ts run start --lab tenancy-demo --home /tmp/demo-home
# Manual (stdlib-only, works on bare python):
python labs/tenancy-demo/server.py --port 0   # prints READY port=N
```

Lab invariants are unit-tested (`services/engine/tests/test_labs.py`) and egress-gated (`services/engine/tests/test_egress.py`) — the same policy that protects public targets protects the lab.

## 7. Providers (model-agnostic, capability-based)

`docs/providers.md` is the full matrix. Summary:

| Provider | Transport | Strict JSON | Notes |
|---|---|---|---|
| `mock` | local | native | Offline dev + conformance third shape |
| `openai-compat` | hosted | native | Any OpenAI-compatible base URL |
| `deepseek` | hosted | native | `reasoning_content` → `reasoning.delta`, `deepseek-reasoner` has no tools |
| `anthropic-compat` | hosted | via forced tool (`structured_via="forced-tool"`, recorded) |  |
| `gemini` | hosted | via forced tool | `x-goog-api-key`, functionDeclarations |
| `ollama` | **local** | no (format=json) | `http://localhost:11434`, no auth |
| `vllm`/`lmstudio`/`openrouter`/`azure-openai` | preset | native | `services/engine/src/scopeforge_engine/models/presets.py` |
| `litellm` | bridge | via forced tool | `uv sync --extra litellm` or gateway via `openai-compat` |

No `---api-key` flag — secret values never enter shell history.

```bash
scopeforge provider add --name work --type deepseek --credential env:DEEPSEEK_API_KEY
scopeforge provider add --name local --type ollama
scopeforge provider add --name g --type gemini --credential env:GEMINI_API_KEY
```

## 10. Troubleshooting

| Symptom | Fix |
|---|---|
| `pnpm: command not found` | `npm i -g pnpm` or `brew install pnpm` |
| `uv: command not found` | `curl -LsSf https://astral.sh/uv/install.sh \| sh` then restart shell |
| `Python 3.11` locally | `uv python install 3.12 && uv sync --python 3.12 --all-extras --all-packages` — repo-local `.venv` will be 3.12 |
| `protocol drift` on `pnpm test` | `pnpm generate:protocol` and commit the regenerated `generated.*` + `envelope.json` |
| `engine not found` from launcher | `pnpm dlx -y tsx apps/terminal/src/index.ts doctor` — checks Node/Python/engine/protocol |
| `provider test --live` fails | `provider test --no-live` checks declared caps without network; for live, set `env:VAR` and ensure `base_url` in `providers.toml` |
| `tool list` shows no tools | `tool` in this harness is constrained wrappers + HTTP egress, not arbitrary shell (see `docs/tools.md`) |
| Lab port in use | `lab.launch` picks a random free port (`--port 0`); `lab.stop` or `pkill -f tenancy-demo/server.py` frees it |
| Windows line endings in fixtures | `scripts/make-provider-fixtures.py` normalizes to LF; do not hand-edit `.jsonl` fixtures |
